# jbriefs reads a brief

`jbriefs` reads a brief, a scout's request or a question and says what it asks for: `jbriefs pick` names the role, the playbook and the skills, and `hooks/skill-tips.sh` gives the one tip a prompt matches. jbus reads a brief's meaning through it when a row is queued.

Paths: `src/jbriefs/`, `hooks/skill-tips.sh`, `docs/jbriefs.md`, `skills/poteto-help/`, `docs/hooks.md`
