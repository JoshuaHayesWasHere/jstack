# make-check-slowness: find what is slowing down `make check` and why

Task: "figure out what is slowing down make check and why"
Done when:
- `make check` has been timed end to end on this machine, with the wall-clock time of each step it runs recorded
- The slowest steps are named, ranked by time, with the measured numbers behind each
- Each slow step has a stated cause backed by evidence, such as profiler output, per-test durations, or a timing comparison, and not only a guess
- The findings are written up and handed back to the home, with any suggested fixes listed as proposals and not applied
Where: the `Makefile` `check` target and every target, script, test suite, linter and type checker it invokes
Do not touch: any change to the `Makefile`, test code, lint or type-check config, or the Python commands. This task is to find and explain the slowness, not to fix it.
Decisions: none
Design: none, it is an investigation that produces findings and no change to the design
Pull request: ask first
Review: none
