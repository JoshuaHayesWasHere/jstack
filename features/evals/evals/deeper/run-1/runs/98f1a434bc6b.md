# ci-chrome-hang: Make jstack's public check finish on `ubuntu-latest` instead of hanging with Chrome still running
Task: "jstack's first public check never finished: two attempts on `ubuntu-latest` hung after the dots reached 92% and 95% and were cancelled at the job's 15-minute limit, with Chrome processes still running"
Done when:
- The public check completes on `ubuntu-latest` well inside the 15-minute limit on two consecutive runs.
- No Chrome or chromedriver processes are left running when the test step ends, whether tests pass or fail. A step at the end of the job lists any leftover browser processes to show this.
- A test that hangs fails on its own timeout and is named in the log, so a stall no longer runs silently until the job is cancelled.
- The full test suite still passes locally.
- The pull request says which tests were running at the 92% and 95% points and what caused the hang.
Where: the CI workflow that runs the public check (`.github/workflows/`), the tests that start Chrome along with their fixtures and teardown, and the test runner config (timeouts, plugins).
Do not touch: the job's 15-minute limit. Do not skip, delete or mark xfail the Chrome tests to get the check green. Leave skills, playbooks and commands unrelated to the hang alone.
Decisions: none
Design: none, this is a bug hunt in CI and test teardown with no design choice to make
Pull request: open one when done
Review: review
