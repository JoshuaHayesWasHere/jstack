# room-psi-edge: measure this machine's real edge and set `make check` workers and `room` admission from it
Task: "I want to push my machine as hard as I can without going over the edge" and "run the test in parallel". Since #339, `make check` runs pytest on six workers. On 2026-10-12 at 21:35 ET, three runners plus crew runs held the one-minute load at 14–15 on 12 cores for over ten minutes. `room` said wait, and pbus could launch nothing (`gate pp-doctor: no room for 10 passes`). Find where the edge of this machine actually is, and set `make check`'s worker count and `room`'s admission rule from that measurement, not from load average.
Done when:
- `hyperfine -w 1 -r 5 -P n 1 12 'pytest -n {n} -q'` has run with PSI sampled each second, and the scaling curve, its knee, and the PSI cpu `some avg60` threshold it names are recorded with the raw numbers
- `make check`'s worker count is set from that knee, and `room` admits on PSI against that threshold instead of on load average
- In a replay of three `make check` runs plus one crew run, captured with `pidstat -u -r -d 1` and `perf stat -a`, `room` admits and pbus launches `gate pp-doctor` with no "no room" refusal over 10 minutes
- Each `make check` in that replay stays within 1.2× its solo hyperfine mean, with spread shown
- PSI cpu `some avg60` stays under the curve's threshold for the whole replay, and `journalctl -k -u systemd-oomd` shows no oomd kill
- `pytest --durations=50` output is attached so the long tail is visible
- The user confirms the desktop stayed responsive
Where: `room`'s source and its threshold; pbus's code and log for the "no room" refusal; the `make check` recipe from #339; `/proc/pressure/{cpu,memory,io}`; `sar -q -u -r -f /var/log/sa/sa12` and `journalctl -k -u systemd-oomd` for 2026-10-12 21:20–22:00; `pytest --durations=0` output
Do not touch: systemd-oomd configuration and kernel or system tuning; pbus's gate logic beyond how it asks `room`; the tests themselves
Decisions: "run the test in parallel"; set the worker count and admission rule "from that measurement, not from load average"; "Install hyperfine and sysstat with pacman if missing."
