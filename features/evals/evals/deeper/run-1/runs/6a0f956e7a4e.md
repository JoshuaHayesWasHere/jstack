# public-release-audit: audit jstack's full git history against a fixed list of public-repo checks and fix findings before it goes public

Task: "We should not take jstack public until it passes every single audit that we could potentially throw at it for what would make a good public repository."

Done when:
- `gitleaks detect --log-opts="--all"` reports zero findings over all history
- `trufflehog git --only-verified` reports zero findings over all history
- The grep across all revisions for the user, .claude/, jbus, localhost ports and email addresses, plus `git log --all --format='%an <%ae>%n%cn <%ce>' | sort -u`, shows only what we chose to publish
- `reuse lint` says compliant
- `licensee detect` names our license
- THIRD_PARTY.md matches each credited source's actual license
- `scorecard --local=.` and Scorecard on a private GitHub push both score ≥ 8/10
- shellcheck is clean and the test suite passes
- A fresh clone in a clean archlinux container and a clean debian container runs the README quickstart, following only README.md, in under 10 minutes
- Every finding is reported with its commit, along with how it was fixed
- One person who is not the user gets it running from the URL alone (the user runs this check, not the crewmate)

Where: the whole repo and its full history (`git rev-list --all --objects`, `git log --all -p`), all refs, README.md, THIRD_PARTY.md, LICENSE, REUSE/SPDX headers, shell scripts, the test suite, CI config

Do not touch: the repo's visibility (it stays private), and the shared remote. Do not force-push rewritten history until the user approves it. Do not fix history with a deleting commit.

Decisions: "Make 'every audit' a fixed list, and audit the full history, not just HEAD." "Fix anything found in history with git filter-repo, not with a deleting commit." "Report every finding with its commit." Scorecard runs "on a private GitHub push."

Design: none, the user fixed the audit list, the tools and the fix method in the request
