# fix-home-limits: Stop homes from running past the limits set on them
Task: "Fix the homes running past their limits"
Done when:
- A home that reaches any of its limits stops starting new work at that point and says which limit it hit
- A test drives a home up to each limit and shows it stops there, not one step past
- The existing tests still pass
Where: the home skill and its playbooks, and the Python commands that start scouts, crewmates and reviewers and count them against a home's limits
Do not touch: the limit values themselves, and the scout, crewmate and reviewer skills except where they report back to the home
Decisions: none
Design: none, the fix enforces limits the home already has and does not change what they are
Pull request: ask first
Review: review
Playbook: none
