Task: "i can montior every single aspect of work in a digestable format"
Done when:
- per-day totals match the Anthropic Console usage export within 0.5% for every token kind (input, output, cache-creation, cache-read) and agree exactly with `npx ccusage daily --json` (the Console export comes from the user; ask for it, don't fetch it)
