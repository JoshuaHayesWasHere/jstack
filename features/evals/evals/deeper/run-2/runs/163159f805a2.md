# public-readiness-audit: Audit jstack against every public-repo check and fix what fails before it goes public

Task: "We should not take jstack public until it passes every single audit that we could potentially throw at it for what would make a good public repository"

Done when:
- A secret scan of the full git history (gitleaks or trufflehog) reports no findings, and any secret it found has been flagged to the user for rotation.
- No personal data is left in tracked files: no home paths like `/home/<user>/`, no personal email addresses, no machine names, no private URLs or tokens.
- A `LICENSE` file is present, and the license is the one the user chose.
- `README.md` says what jstack is, what it needs, how to install it, a quickstart for the home thread, scouts, crewmates and reviewers, and how to contribute.
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, issue templates and a PR template are present, and GitHub's community profile shows 100%.
- The Python commands pass a linter and formatter (ruff), a type check, and the test suite, all in a CI workflow that runs on PRs.
- A dependency audit (pip-audit or equivalent) and a static security scan (bandit or equivalent) report nothing unaddressed.
- Skills and playbooks hold no instructions or paths that only work on the author's machine. A fresh clone set up by following the README works.
- `.gitignore` covers local state, caches and memory files, and none of those are tracked.
- `AUDIT.md` lists each audit run, its result, and what was fixed or knowingly accepted.

Where: the whole jstack repo: skills, playbooks, Python commands, docs, CI config, and git history

Do not touch: the repo's visibility (do not make it public); git history rewrites (propose them, do not run them); remote repo settings

Decisions: "We should not take jstack public until it passes every single audit that we could potentially throw at it"

Design: none, this is an audit and cleanup against known public-repo checks, with no architecture choice to make

Pull request: ask first

Review: review

Playbook: none
