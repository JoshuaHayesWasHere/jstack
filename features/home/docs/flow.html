Every message a thread sends

A thread messages its home only when the home has something to do. No thread sends a message when a pull request opens, when a review is written, or when its findings are handled.

Whom a message goes to

The id in a home-id, read when the message is sent: the root home's, or the one in <scope>/ when the Home: line of the brief or request names that scope. No brief names a thread. With no home listening, the thread sends nothing, and the next home reads the result from disk.

The root home and a scoped home

A repo has one root home, and may have scoped homes beside it, each for one goal. Briefs, requests and standing rules are shared. A handoff and a plan are a home's own, and jbus keeps each home's gates.

  • Only the root home makes a scope, and only on your word.
  • No home writes another home's directory.
  • A scoped home's slugs and branches start with its prefix.
  • jbus is the only merger: it runs jmerge on each pass whatever home-thread holds, and it merges every home's pull request, a scoped home's too. A home's own jmerge --home <threadId> merges nothing.
  • Homes never send each other a message of their own. The root carries your word to a scope with jbus word --scope, a scope reaches the root only with jbus stop, and a fault found in another home's work is a queued row of that home's.
  • No home asks another what it has out: jmerge --claims prints it.
  • A scoped home closes at its handoff when its plan has no open entry and jbus out --scope prints nothing, and then it starts no next home.
  • The root home reads a scope's handoff and open plan entries when you ask for status.

What "ready" and "removable" mean

Ready: a review is written, and its findings are handled (Fixed:). A wider fix has had its second pass. The check named check, or each check that the repo's required-checks file lists, has passed at the pull request's head. That green run still covers today's main. GitHub says the pull request can merge. Its queue row has your go, or the bot's. Its own browser run, where it has one, has not failed. Main is not red, or this pull request is the fix of that red. The rules are in features/jmerge/src/jmerge/ready.py. Removable: the last Result says done with nothing left, the pull request is merged or there is none, and nothing uncommitted or unpushed would be lost. The rules are in features/jmerge/src/jmerge/sweep.py.
