These skills shape an idea before it becomes a change.

| Skill | Starts | Does | Source |
| --- | --- | --- | --- |
| `prototype` | Phrase: "prototype" | Explores a vague request on throwaway `proto/` branches. Tries two or more routes, reports what each showed, and asks what to keep. Never opens a PR. | jstack |
| `in-your-own-words` | Typed | Restates your goal and the problem behind it before any work starts. | pstack |
| `architect` | Typed | Settles types, signatures, and module shape before code crosses a function boundary. Stays involved while the code is written. | pstack |

For the full rules of `prototype`, see [[Modes]].
