These skills help with the work around the work. All of them come from pstack and run only when you type them.

| Skill | Does |
| --- | --- |
| `reflect` | Reads the current chat for lessons and turns each one into an edit to an existing skill. |
| `correct` | Finds mistakes that agents keep repeating in a repository and makes each one impossible. Tries architecture, then types, then a lint, then a test, and writes docs last. |
| `teach` | Runs `how` and `why`, then explains the work plainly, one diagram at a time. |
| `no-comments` | Starts the `comment-sicko` agent to strip comments from a diff, then fixes the findings you accept. |
| `statechart` | Checks a TLA+ model of a system that moves between states and draws it as a Mermaid statechart. Shows the shortest path to each state that breaks a rule. |
| `ketchup` | Catches you up on what changed in the chat since your last message. Lists every item that waits on you. |
| `recall` | Rebuilds your recent context on a topic from your chat history and live state. |
| `unslop` | Removes signs of AI writing from text. |
| `bro` | Restates the last message in plain words. |
