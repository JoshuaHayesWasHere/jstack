# Security

Report a security problem privately, through GitHub's private vulnerability reporting: on the repo's **Security** tab, choose **Report a vulnerability**. The report is seen by the maintainer only. Do not open a public issue or pull request for it.

Say what is affected, how to reproduce it, and what somebody could do with it.

jstack is maintained by one person in spare time. No response time is promised, and neither is a fix.

Only the latest commit on `main` is looked at: there are no older versions that get fixes.
