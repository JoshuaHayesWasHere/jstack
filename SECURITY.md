# Security

Report a security problem privately, through GitHub's private vulnerability reporting: on the repo's **Security** tab, choose **Report a vulnerability**.
Only the maintainer sees the report.
Do not open a public issue or pull request for it.

Say what is affected, how to reproduce it, and what somebody could do with it.

Reports cover the latest release and `main`.
A fix goes into `main` and the next release, and no older release gets one.

jstack is maintained by one person in spare time.
No response time is promised, and neither is a fix.
