# fix-home-limits: make homes stop at their limits instead of running past them

Task: "Fix the homes running past their limits"
Done when:
- A home that reaches one of its configured limits stops starting new work and reports that it hit the limit.
- A test drives a home to each limit and fails if it runs past it.
- The existing test suite passes.
Where: the home skill and its playbooks, and the Python commands that count and check a home's limits
Do not touch: the limit values themselves; limits for scouts, crewmates and reviewers
Decisions: none
Design: none, this is a fix that enforces limits the home already has, so it needs no design call
Pull request: open one when done
Review: review
Playbook: none
