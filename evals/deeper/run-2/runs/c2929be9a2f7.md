# public-release-audit: Audit jstack's full git history against a fixed checklist of public-repo checks and report each with its command and raw output
Task: "We should not take jstack public until it passes every single audit that we could potentially throw at it for what would make a good public repository."
Done when:
- "Every audit" is written down as a fixed checklist, and each item names its command and its pass bar.
- The audit covers the full history: `git rev-list --objects --all`, all branches and tags, every blob and diff, not only HEAD.
- The author and committer identities from `git log --all --format='%an <%ae> | %cn <%ce>'` are listed, deduplicated, for the user to review.
- `gitleaks detect --log-opts="--all"` reports zero findings over all history.
- `trufflehog git file://. --only-verified` reports zero findings over all history.
- `reuse lint` reports compliant, with every file's licence header checked.
- `scancode -clpi` has been run and its licence, copyright, package and info results are reported.
- `osv-scanner -r .` is clean across the lockfiles, or each finding has a written justification.
- `scorecard` scores ≥ 8.
- A fresh clone in an empty directory, built and tested with the README's build and test commands in a clean-room `docker run`, passes its tests with no edits.
- Any history fix the scans call for is done with `git filter-repo`, and the scans are rerun on the rewritten history.
- The report gives every check with its exact command and raw output.
- The author list and README are put in front of the user for sign-off. Only the user can give that sign-off.
Where: The whole git history (all refs, branches and tags), author and committer metadata, lockfiles, licence headers and `LICENSES/`, `README` with its build and test commands, and a fresh clone in an empty directory.
Do not touch: Do not make the repo public. Do not push or force-push rewritten history to any remote, and do not replace the working repo's history. Run `git filter-repo` on a separate clone and wait for approval before that history goes anywhere. Do not edit the tests or the README's build and test commands to get the clean-room run to pass. Do not sign off on the author list or README on the user's behalf.
Decisions: "jstack is ready to go public only when gitleaks and trufflehog report zero over all history, `reuse lint` is compliant, osv-scanner is clean or each finding is justified, Scorecard is ≥ 8, the clean-room build passes its tests unedited, and I have signed off on the author list and README myself." "Use `git filter-repo` for any history fix the scans call for."
Design: none. This is an audit with fixed tools and pass bars the user has already set, so there is no design call to make.
