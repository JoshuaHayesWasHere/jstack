# fix-home-limits: Stop homes from running past their limits

Task: "Fix the homes running past their limits"
Done when:
- A home that reaches one of its limits stops or hands off at that limit instead of running past it
- The check runs for both the root home and scoped homes
- A test fails on the current code and passes with the fix
- Existing tests still pass
Where: the home skill and its playbooks, and the Python commands that track and enforce a home's limits
Do not touch: limits and behaviour for scouts, crewmates and reviewers; the values of the limits themselves
Decisions: none
Design: none, it is a fix to make homes keep limits they already have, not a new design
Pull request: open one when done
Review: review
Playbook: none
