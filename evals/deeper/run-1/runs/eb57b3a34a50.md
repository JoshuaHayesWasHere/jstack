# release-audit: turn "every audit" into a fixed checklist in docs/release-audit.md, run it, and report a go/no-go verdict on taking jstack public
Task: "We should not take jstack public until it passes every single audit that we could potentially throw at it for what would make a good public repository."
Done when:
- ~/jstack/docs/release-audit.md exists as a fixed, finite checklist, and each line names one audit, the command that runs it, and its pass line
- gitleaks and trufflehog both report 0 findings over all history (`--all`, every branch)
- `reuse lint` exits 0 and licensee recognises the license
- osv-scanner reports 0 unexcepted vulnerabilities on the lockfiles
- OpenSSF Scorecard is >= 8.0 (`--local`, then `--repo` on a private GitHub copy)
- zizmor reports 0 high findings on .github/workflows/*.yml
- the strictest linter for each language in the repo passes
- a cold install in a clean archlinux or debian container works when it follows README.md verbatim, and the tests pass in that container
- one human other than the author has read the repo cold and said "ready"
- the report gives each audit's raw output against its pass line, lists every failure as it stands, names each tool that had to be installed, and ends in a verdict
Where: ~/jstack, which means all of its git history and branches (`git log --all -p`, `git rev-list --all --objects`), the author/committer identities (`git log --all --format='%an <%ae>%n%cn <%ce>' | sort -u`), `git ls-files`, LICENSE, the lockfiles, .github/workflows/*.yml and the logs of their last runs, README.md, and docs/release-audit.md (new)
Do not touch: publishing of any kind. Do not make the repo or the GitHub copy public, push to a public remote, tag, or cut a release. Do not force-push rewritten history to any remote.
Decisions: "Start from the raw repo, not its current tree"; "Grep for the user, personal emails, local hosts and private keys"; "git filter-repo --analyze (and rewrite the history if anything is found, before going public)"; "OpenSSF Scorecard (--local, then --repo on a private GitHub copy)"; "a cold install in a clean archlinux or debian container that follows README.md verbatim"; "Install any tool that is missing, and say which"; "Do not publish anything. This task ends at a verdict, not at the release."; "Report every failure as it stands."
Design: none. This task is an audit with a checklist and a verdict. The user already fixed the tools, the pass lines and the scope, so there is no design call left to make.
