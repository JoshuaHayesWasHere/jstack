### Act On

**1. The retired `[exec]` table now loads silently, and its `webhook_url`/`webhook_key` are no longer redacted** (A1, B1)
`src/jbus/__init__.py:42` and the removed `_unread`/`Config.unread`. Before this PR, a leftover `[exec]` table or `exec_watch` key produced an "ignored: … remove them" notice, and its URL and key went into `secrets()`. The PR deleted both behaviours and the test that pinned the redaction. The brief said to keep behaviour a test still needs, renamed. Deleting the test as well sidesteps that line rather than meeting it.

The exposure is narrow. The user's config has no `[exec]` table, and nothing reads that table, so the URL would only leak if something else quoted it. Still, both reviewers raised it independently, it is a security path, and the fix is cheap.

The fix: restore a neutral retired-table notice that redacts any `webhook_url`/`webhook_key` in a table nobody reads, and restore its test under non-Exec names. `__init__.py` is outside "Where", but this PR already edits it, so restoring the behaviour belongs here.
