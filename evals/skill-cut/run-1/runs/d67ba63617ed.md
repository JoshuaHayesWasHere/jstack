First, I'd grep every `Task` producer and consumer (`rg -n "doneAt|status ===|status:" src`) so the compiler and I know what will break. I'd follow "Make illegal states unrepresentable" rather than adding another optional `cancelledAt?` field. The bag-of-optionals shape already admits `status: 'open'` with a `doneAt`, and a third timestamp would multiply the bad combinations. So I'd write `type Task = { status: 'open' } | { status: 'done'; doneAt: Date } | { status: 'cancelled'; cancelledAt: Date }`. Then, per "Exhaustive matching", every `switch (task.status)` gets a `default: { const _x: never = task; }` arm, and I'd fix each compile error `tsc --noEmit` reports, including the parse function at the persistence/JSON boundary.
