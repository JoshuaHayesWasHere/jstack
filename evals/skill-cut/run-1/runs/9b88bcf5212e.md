First, I grep for every `Task` construction and every read of `status`/`doneAt` so I know which sites will need updating. I'm following "Make illegal states unrepresentable": the current type already allows `status: 'done'` with no `doneAt`, and adding a `cancelledAt?` field next to it would make that worse.
Instead, I rewrite the type as a discriminated union:
`type Task = { status: 'open' } | { status: 'done'; doneAt: Date } | { status: 'cancelled'; cancelledAt: Date };`
Next, under "Exhaustive matching is the compiler's job", I convert every `switch (task.status)` to end in `default: { const _exhaustive: never = task; throw new Error(...) }`. That way `tsc` points to each site that is missing the new case.
The command I run is `npx tsc --noEmit`, and I fix each error it reports (old `doneAt?` reads, missing `cancelled` branches). I don't add casts to silence them, per "Don't lie to the type system."
