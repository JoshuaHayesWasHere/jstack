Each finding gets one line in the form `<severity> <file>:<line> <what is wrong> (principle: <name>)`:
`error <file>:<line> <what is wrong> (principle: <name>)`
`info <file>:<line> <what is wrong> (principle: <name>)`
Before keeping the nit at `info`, I check whether it must be fixed in this pull request. If it must, I rate it `warning`, because a crewmate declines `info` findings by default.
Both lines then go in place of `<the findings, one to a line>` in the "Outside the diff" block, step 2 of "After the review". I keep only what that block prints.
