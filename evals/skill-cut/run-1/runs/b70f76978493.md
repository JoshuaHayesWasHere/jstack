**1. The new "how to tell" test calls depth "breadth"** (A1, B2, merged)
- **Where:** `principles/depth-over-breadth.md:15`, against `:13`.
- **Problem:** Line 15 says deeper work "reaches the same outcome" and leaves the "Done when" alone, while wider work changes the outcome. Line 13's third question (*What says it is done?*) is itself a rewrite of the "Done when": an outside judge, a measured target, or a test that fails before and passes after. Read literally, the test files the principle's own deepest move under "Noticed".
- **Why it blocks:** This is the one new decision rule the rewrite adds, the "and how to tell" from the Done-when line, and it is the part that is wrong. Both reviewers traced the same concrete contradiction.
- **Fix:** Base the test on deliverables. Deeper work keeps what is delivered and changes where it starts, what it measures with, and what judges it. Wider work adds a deliverable.

**2. "say *why* it is reasonable" changes the rule** (B1)

- **Fix:** Restore "and say it is reasonable". If the reasoning style wants a reason, add one clause on *why* that works.
