First, I won't add `cancelledAt?: Date` next to `doneAt?`, because that is the bag-of-optionals the file warns about. I follow "Make illegal states unrepresentable" and turn the type into a sum type:
`type Task = { status: 'open' } | { status: 'done'; doneAt: Date } | { status: 'cancelled'; cancelledAt: Date };`
Next, per "Exhaustive matching is the compiler's job", every `switch (task.status)` gets `default: { const _exhaustive: never = task; throw new Error(...) }`. That way `tsc --noEmit` flags each site that doesn't handle `'cancelled'`.
Then, per "External data is untyped until parsed", I update the parser at the boundary (JSON or DB rows) to build the new variants, so no `as Task` casts are needed.
