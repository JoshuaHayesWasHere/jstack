### Intent
> Replace pr-review's two reviewer subagents (A/B) with one review thread. That thread reads the PR's diff itself, with the same intent, `SCOPE` and seven questions, and keeps the blast-radius proof. It sends one combined review and writes one `## Review` section with `Reviewers: 1`, which jmerge's unchanged `ready.py` still reads as ready. jbus archives the review thread when the PR merges or closes, and never while the PR is open. Skills and docs that say "two reviewers" now say one. Tests cover the skill text, the archive on merge and its absence while open, and jmerge reading the new section; `make check` exits 0.

### Act On

**1. "Closed" is inferred from absence, and the result is now an archive** (A2, B1, merged)
- `shut()` treats a slug as closed when its Result's URL is missing from a 100-item open-PR list.
- A PR past the 100th, a URL that differs in form, or a slug mismatch would archive the review thread of a PR that is still open. The Done when line explicitly forbids that.
- B1 adds that this is a second definition of "closed" that already disagrees with `watch.pull` (the `eta`/`pull/8` case).
- This is the one destructive path in the change, so it gets the strictest reading.
- Fix: decide "closed" in one place, from real state. That means `world.merged` plus a state GitHub reports as `CLOSED` (cached the way `merged.json` is), not absence from a list.
- Simply reusing `watch.pull`, as B1 suggests, gives one definition, but by B1's own description it is also absence-based. On its own it fixes the disagreement, not the open-PR risk.

**2. The jmerge new-shape test never lists a finding** (A1)
- `Findings:` in the template has no trailing space, so the `": "` fill never fires.
- The section jmerge reads therefore has `Verdict: findings` with zero listed findings. The rule "each listed finding has its `Finding:` line" is never exercised.
- That is the core of "jmerge's ready rule still passes on that section", and the test would pass even if the matching broke.
- Fix: write a real `- warning …` item under `Findings:`. Add the negative case, the same section with no `Finding:` line, which must not be ready.

**3. `docs/flow.html` still says "Two reviewers"** (A3)
- This is a Done when line that is not met: "any other skill or doc that tells pr-review to start two reviewers says one".
- The page is hand-written, not generated, so the docs sweep won't fix it, and `test_flow_doc.py` doesn't catch it.
- Fix: update the page. Optionally extend the skill-text test to grep the docs for "two reviewers", per encode-lessons-in-structure.

**4. Step 4 claims an independent check that no longer exists** (A6, B2, merged)
- `skills/pr-review/SKILL.md:232` tells the lead to judge "against what the reading was not given: the brief's decisions". In one thread, the reading had the brief.
- This is skill text that misleads the agent running it about its own epistemic position, and both reviewers caught it.
- It is a one-sentence fix: say the reading and judgment are the same thread, and point the judgment at re-checking each claim against the repo and the brief.

### Consider

- **Archive is a mode flag inside a title-prefix map** (A4).
  - Computing `ended` once and deriving `("settle", "archive")` from `role_of(title)` and `slug_of` would remove the `"archive"` key, the `shelve` propagation and the nested loop with `break`.
  - It's a real simplification, and it fits naturally if Act On #1 already reworks `shut()`. On its own it isn't blocking.
- **A merged PR's review thread stays if the last Review is `not run`** (A5).
  - After a merge the thread waits on nothing, so the verdict condition no longer protects anything.
  - It's narrow in practice, since jmerge needs a review of the head to merge. Still, the cost of archiving non-busy review threads for slugs in `ended` regardless of verdict is low.
- **Test fake fidelity and legacy subagents** (B3).
  - The fake keeps listing archived threads, so behaviour after an archive (where T3 may hide them) is untested. Making the fake drop them is cheap and checks what T3 actually shows.
  - The settled-subagent half only affects reviews started under the old skill. That is transitional, so lower priority.

- **`docs/jbus.md:108` phrasing** (A8): accurate in substance but ambiguous. It is worth rewording when touching that section for Act On #1, whose fix will likely change the sentence anyway.
