### Act On

**1. The step-5 tick reply now has two owners that disagree** (A1, B1)
- Step 5 still says "work each tick as 'One tick' says". One tick step 4 says to report "what this tick changed… nothing that an earlier message said".
- The new sentence says to catch up per ketchup. Ketchup's scope is everything since the user's last message, and on autopilot that can be many ticks old.
- The result is that each hourly reply re-reports earlier ticks, or the new sentence is dead text.
- Both reviewers traced the same concrete path, so this is a consensus correctness issue in what the home actually does.
- Fix inside Where: scope the catch-up in step 5 to "what this tick changed", so the two rules agree.
- Moving the rule into One tick step 4 (`skills/home/queue-and-its-hourly-audit.md`) is the cleaner long-term home, but it is outside Where. Note it for later; don't do it here.

**2. "Changed something *for the user*" leaves ticks that fit neither sentence** (A2, B3)
- The "Done when" line says "a tick or reply that changed something". The diff added "for the user", which creates a third case: a launch, a stuck-thread re-send, or a pickup.
- Ketchup's "leave out work that changed nothing for the user" means that third case can end silently. One tick step 4 explicitly requires reporting it.
- Dropping "for the user" makes the two sentences partition every tick and matches the task's own wording. It is a one-phrase fix.

**3. Hand over (both playbooks) asks for content that ketchup tells the writer to cut** (A3, B2)
- Hand over asks for the per-entry link, state and PR, and for "what merged, with the commit".
- Ketchup asks for under 150 words, no hashes unless needed to act, and cutting history before action items.
- A queue of any real size cannot satisfy both, and the sentence doesn't say which wins. The losing side is the full accounting that step 7 requires.
- Fix: state precedence. One way: "account for each entry as step 7 says; catch the user up per ketchup on the rest". Another: say the listed items override ketchup's length and hash rules.
- Check the result against the 8043881 drift diff, so any deviation from upstream is a deliberate local form, not an accident.
