I do **not** run the suite: running it writes caches and build output and starts processes, so it is not a read-only call. I can't run anything here anyway.

1. **Research section, "Every tool call only reads…":** a question that needs such a run is not answered by a guess. I record that in the report and leave the run to a crewmate.
2. **Find the exact command first, read-only:** I read `package.json`, the `Makefile` or the CI config to see what the suite command is (for example `npm test`). That is so the crewmate runs the right thing.
3. **Write it down, the report under "Findings":** `Q<n> (suite time on this machine): not answered. Answering it needs a run of the full suite, and a scout runs nothing that writes. Docs, logs and git history give no recent number (ruled out: <paths/commands checked>). What would answer it: a crewmate runs \`time <suite command>\` from a clean checkout and records the wall time.`
4. If the request asks for a brief, I put that timed run as a "Done when" check in `$H/tasks/<slug>.md`. Then I go on to the next question.
