First, don't add `cancelledAt?: Date` next to `doneAt?`. That would multiply the contradictory combinations that already compile.
Following "Make illegal states unrepresentable" (and "Types are constructions"), replace the bag of optionals with a sum type:
`type Task = { status: 'open' } | { status: 'done'; doneAt: Date } | { status: 'cancelled'; cancelledAt: Date };`
Then, per "Exhaustive matching is the compiler's job", make every `switch (task.status)` end in `default: { const _x: never = task; throw new Error(String(_x)); }`. The compiler then flags each site that's missing the new case.
Next, per "External data is untyped until parsed", update the boundary parser (JSON or DB row → `Task`) to build the new variant. If a schema owns this shape, change the schema and regenerate the type instead of hand-editing it.
Finally, I'd run `npx tsc --noEmit` and fix each reported site.
