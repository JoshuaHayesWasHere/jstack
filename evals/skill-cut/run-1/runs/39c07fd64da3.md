Any such brief approved after 11:15 gets gated with "no size". Adding the line changes the brief's sha, which re-gates the row as "changed after approval". That is the stranded row the Done-when forbids.

Both reviewers traced the same concrete path on their own. The live-queue check passed only because the latest approval was 11:06; it shows a moment in time, not a guarantee. Set the cutoff from the actual merge, or later, and add a test for a row approved between the old constant and the merge. Then re-run the live-queue check against today's queues, since a day has passed since 10-15.
