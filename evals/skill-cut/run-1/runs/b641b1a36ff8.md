### Intent
> Sections 1, 2, 5 and 6 of the /deeper design, built on Felix Rieseberg's "four types of ambition": a manual `/deeper` skill that answers the four questions and gives a rewritten prompt (non-blocking, with a `jbus gate` to keep the original or use the rewrite); the 25th principle, `depth-over-breadth`, with jdrift and every principle count updated; the credit in `THIRD_PARTY.md`; and a blind, rerunnable eval in `evals/deeper/` over about 10 past briefs. The eval's Result must say honestly whether /deeper won. A loss is a finding, not a reason to tune.

### Reviewers
- Reviewer A: 5 findings (3 warnings, 2 nits), all in `evals/deeper/`.
- Reviewer B: 8 findings (4 warnings, 4 nits), across the eval, the skill, the principle card and jdrift.
- Neither reviewer named a "Done when" line as unmet: the skill, `install.sh`, the counts of 25, `THIRD_PARTY.md` and the jdrift test passed both readings. Both reviewers' findings point at the eval, specifically whether its verdict holds up.

### Act On

**1. The verdict "won" rests on one run and on a measure that rewards backticks** (A1, B1)
- A1: the whole plain-to-deeper rise in "outside" comes from the backtick branch of `OUTSIDE` (`evals/deeper/score.py`). A1 rescored the committed briefs to show this: without that branch the two arms are level, at 0.34 and 0.33.
- B1: run 1 lost under the rule. Run 2 changed only the output format of the skill (a fence became a block quote), and outside then flipped sign on eight of ten cases.
- Put together, the measure that decides "lost on none" is a formatting proxy, and it is noisy between two runs of what is in effect the same skill. The task warned against exactly this: "If it did not, say so: that is a finding, not a reason to tune the eval."
- **Fix:** drop the bare-backtick branch, or limit it to commands that are actually run. Then rescore the committed briefs, which needs no model calls, and restate the Result. Something like: "won on raw sources and instruments in both runs; proof outside: no effect shown". Do not report an 8/2 win.
- This is the headline deliverable of the PR, so the claim must be accurate.

**2. The "raw sources" measure mostly counts the skill's own list, yet the README says it doesn't** (A2, B2, consensus)
- Seven of the twelve `RAW` kinds echo answer 2 of `SKILL.md` word for word.
- Instruments have a `beyond` count that leaves out the skill's examples. Raw has none.
- The README nonetheless claims the effect holds "not only by copying the skill's own examples".
- **Fix:** add a `beyond` count for raw, mirroring `SKILL_EXAMPLES`, and rescore with no new calls. Alternatively, narrow the sentence to instruments only.
- Both reviewers found this independently, and it is a stated claim the evidence does not back.

**3. `write()` wipes the committed runs before any model call** (A3, B3, consensus)
- `shutil.rmtree` on `runs/` and `deeper/` runs first, and `key.json` is written only at the end.
- A missing `claude` binary, a failed call or a timeout therefore leaves partial briefs and a stale key. There is no resume, and recovery is only possible from git.
- This is the crash-halfway case the review asks about, and it sits in the one command the README tells people to run.
- **Fix:** write into a temporary directory and swap it in once the key is written. A `shutil.which("claude")` precheck is a cheap addition, but it does not replace the swap.

**4. Redaction is skipped silently when the jleak config isn't at `~/.config`** (B4)
- `_private` hardcodes `Path.home() / ".config"`, whereas `jleak.cli` respects `XDG_CONFIG_HOME`.
- It then swallows `jleak.Missing` and returns `()`, so cases and model outputs go into a public repo unredacted.
- This comes from one reviewer, but it is a privacy finding on a concrete path, and the fix is small.
- **Fix:** resolve the path the way `jleak.cli` does, and fail when the patterns cannot be loaded instead of carrying on without them.

**5. The principle card claims playbooks that don't use the principle** (B6)
- The leans field lists `perf-issue` and `investigation`, but neither references `depth-over-breadth`.
- The other cards' leans match real references, and this card is rendered on `docs/jstack-explained.html`.
- **Fix:** list only `deeper`. This is a one-line change inside the Where line. Linking the playbooks is out of scope and is for later.

**6. The gate's `Context:` placeholder invites four lines, and jbus keeps one** (B7)
- `mirror.field` reads only the `Context:` line, so answers 2 to 4 would be lost from the gate record.
- The test fills in a single joined line, so it never exercises the reading the wording suggests.
- **Fix:** reword the placeholder to say "on this one line, separated by semicolons". It is cheap and inside `skills/deeper/`.

### Consider

**The "Not held" column counts a phrase, not a fact about each brief** (A4)
- The column feeds the README's "seven of the ten" sentence about how merged briefs turned out.
- It counts "does not hold" anywhere in the brief and misses tense variants.
- Limiting the search to the Result section and matching "did not hold" and "doesn't hold" is cheap. The README could also simply call it a phrase count.
- **Tradeoff:** it affects one descriptive sentence, not the verdict.

### Noted
- **A5:** `eval.py` leaves `evals/deeper` and `src` on `sys.path` and registers a top-level `score` module for the rest of the test session. It is real hygiene, but nothing collides today.
- **B5:** `SELF` disqualifies any proof line that mentions "review", which depresses `rs-parallel-reviews` in both arms. It is a measurement wart on one case and does not favour either arm.
- **B8:** `Pinned.own = ()` is a default nothing uses. Removing it is harmless and optional.

### Dismissed
None. Every finding names a concrete line and a concrete effect.

### Agreement Map
- **Where they converged:** both reviewers independently found the same two eval problems, the raw measure echoing the skill's list (A2/B2) and the destructive `write()` (A3/B3). That is a strong signal.
- **Where they complemented each other:** A1 and B1 reach the same conclusion about the verdict by different routes. A1 shows the outside measure is a backtick proxy; B1 shows the verdict flipped between runs. Neither alone is decisive, but together the "won" claim falls apart.
- **What B added:** B read more widely and found the privacy hole, the gate wording and the card claim. A stayed inside the scorer.
- **What this tells us:** the skill, the principle, the jdrift change, the credit and the counts are sound apart from nits. The weak point is the eval's measures and how its Result reads them. Every eval fix above can be done by rescoring the committed briefs, with no new model calls. The likely honest outcome is "raw sources and instruments up in both runs; proof outside not shown", and the Result should say that.
