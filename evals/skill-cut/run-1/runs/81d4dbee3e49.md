First I replace the cast with a parse at the boundary, following "External data is untyped until parsed" and "Don't lie to the type system". If the repo has a schema that owns `Order`, I derive the parser from that ("Derive types from authoritative schemas").
I write: `const order = parseOrder(JSON.parse(body) as unknown);`
`parseOrder` returns `Result<Order, ParseError>`, or it throws a 400. It validates `items` as an array, so `order.items.length` is proven, not assumed.
If a zod schema already exists, I write `const order = OrderSchema.parse(JSON.parse(body));` and use `type Order = z.infer<typeof OrderSchema>`.
Then I grep for other `as Order` casts with `rg "as Order\b"` and route those through the same parser.
