I don't run the suite. Running tests writes caches and build output and starts processes, so it isn't a read-only call. "Research" says: *"If a question needs such a run to answer, say so in the report and leave the run to a crewmate."*

This is not a gate either, because the user isn't the only one who can answer it. A timed run can.

So I mark the question unanswered in the report. It goes under "Findings" in `## Report` of `$H/scouts/<slug>.md`, per "Write it down" and `$T/scout-report.md`. The line would be:
`Q<n> suite runtime: unanswered. No recent number in docs, logs or history; measuring needs a run that writes state, out of a scout's reach. Answer: a crewmate runs `time <the repo's test command>` on this machine.`

If the request asks for a brief, that timed run also goes in its "Done when" list. I can't execute or write anything here, so these are the steps I'd take, not ones I've taken.
