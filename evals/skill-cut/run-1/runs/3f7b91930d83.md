### Act On
- **The depth-or-breadth test at line 15 contradicts the third question at line 13** (A1, B2). Line 15 says deeper work "reaches the same outcome" and wider work "changes the outcome", measured against the "Done when". But the third question ("What says it is done?") changes the "Done when" on purpose, by adding a failing-then-passing test, a measured target or an outside judge. Read literally, the test classes depth's main move as breadth, so a home would send it to "Noticed". It would also go against `/deeper` question 4. Both reviewers found this on their own, it shows a concrete misclassification, and it is the one new decision rule the rewrite adds. Fix: base the test on deliverables. Deeper work keeps what is delivered and changes where the work starts, what it measures with and what judges it. Wider work adds something to deliver. B2's point that "answers them by adding a deliverable" muddles the sentence goes away with the same fix.
- **"and say *why* it is reasonable" changes the rule** (B1, line 13). The task asked for a change of style, not of meaning. The original move is to tell the worker that an ambitious target is reasonable. This line turns it into a duty to justify the target. After the change, the principle disagrees with `skills/deeper/SKILL.md` question 4, which is out of scope and so cannot be updated to match, and with the credit in `THIRD_PARTY.md:260`. Restore "and say it is reasonable". If the reasoning style needs one, add a clause on why the move works.
