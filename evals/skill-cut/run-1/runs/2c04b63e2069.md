### Act On

**1. Step 5's catch-up contradicts "One tick" step 4** (A1, B1)
- **The conflict:** step 5 still says "Work each tick as 'One tick' says". One tick's step 4 says to report only what this tick changed, "Nothing that an earlier message said". Ketchup covers everything since the user last wrote. In autopilot that can be many ticks ago, so each hourly reply would grow and repeat earlier ticks.
- **Why it blocks:** the home now has two rules for one reply, and nothing decides which wins. This is a concrete path, not a hypothetical, because autopilot runs with the user away. B notes that upstream's One tick lacks the one-line-each rule, so this conflict is specific to jstack and the drift diff won't show it.
- **Fix inside Where:** limit the catch-up in step 5 to "what this tick changed, nothing an earlier message said", using ketchup's voice.
- **Noted for later (outside Where):** making One tick step 4 itself point to ketchup is the cleaner end state.

**2. The Hand over lines require what ketchup tells the writer to cut** (A3, B2)
- **The conflict:** both Hand over lines demand a full per-entry account (link, state, pull request, merges with commits). The same sentence makes that account subject to ketchup's rules: under 150 words, no hashes, cut "what happened" first.
- **Why it blocks:** a queue of any real size cannot satisfy both. The cutting order drops exactly the step-7 accounting the Hand over exists to deliver.
- **Fix:** say which wins. For example: "account for every entry as below, kept whole and not cut for length; catch the user up per ketchup on the rest."

**3. "Changed something *for the user*" leaves a gap** (A2, B3)
- **The gap:** the "Done when" line has two cases, "changed something" and "changed nothing". The added "for the user" creates a third case: a tick that only launched a crewmate or picked up a stuck thread. That tick fits neither sentence. Under ketchup's "leave out work that changed nothing for the user", it could end with no message. One tick explicitly requires reporting those.
- **Fix:** drop "for the user". A rated this a warning and B a nit, but it fails the "Done when" wording and the fix is one phrase.
- **Caveat:** if upstream 8043881 uses "for the user" verbatim, the jstack-local form is justified by the One tick difference. Note that in the PR so the drift diff reads as intended.
