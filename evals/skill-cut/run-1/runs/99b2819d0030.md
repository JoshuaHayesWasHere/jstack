First, I replace the unchecked cast with a parse at the boundary, following the bullet **"External data is untyped until parsed."** `JSON.parse(...) as Order` only claims the shape; `order.items.length` will throw at runtime if `items` is missing.

Line I write: `const order = parseOrder(JSON.parse(body) as unknown);`. Here `parseOrder(input: unknown): Order` validates the input (Zod `OrderSchema.parse`, or a hand-written guard) and throws a typed 400 error on bad input.

If an OpenAPI or protobuf schema already owns `Order`, I derive the schema or type from it instead of writing it by hand (bullet **"Derive types from authoritative schemas"**). I'd check that first with `grep -rn "Order" --include=*.{yaml,proto,json} .`
