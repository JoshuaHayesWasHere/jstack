1. **I don't run the suite.** Running tests starts processes and writes caches, so it isn't a read-only call. "Research" says: *"If a question needs such a run to answer, say so in the report and leave the run to a crewmate."*
2. **First, I find the exact test command with read-only calls**, such as `Read` on `package.json`, `Makefile` or `.github/workflows/*.yml`. If CI exists, I also check `gh run list --limit 5` for durations, but those are from CI runners, not this machine.
3. **I don't guess or open a gate.** The user can't answer this either. Only a run can.
4. **Under "Findings" in the `## Report` of `$H/scouts/<slug>.md`, I write:** `Suite time on this machine: not answered. Needs a run, which a scout may not do. A crewmate runs: time <test command> (CI took <n> min, <run URL>, not this machine).`
5. If a brief is asked for, I put that `time …` run in its "Done when" list. Then I carry on with the other questions.
