First, check whether a schema already owns `Order` (OpenAPI, protobuf, or a zod/valibot schema in the repo): `rg -n "Order\b" --type ts -g '!node_modules'` plus a search for `OrderSchema`.
I follow "Don't lie to the type system" and "External data is untyped until parsed": `as Order` is a cast on an HTTP body, which is a boundary, so `order.items.length` can crash at runtime.
If a schema exists, derive from it ("Derive types from authoritative schemas"). Otherwise, define `const OrderSchema = z.object({ items: z.array(ItemSchema), ... })` and `type Order = z.infer<typeof OrderSchema>`.
Then I replace the cast with: `const parsed = OrderSchema.safeParse(JSON.parse(body)); if (!parsed.success) return badRequest(parsed.error); const order = parsed.data;`
I also wrap `JSON.parse` so malformed JSON returns a 400 rather than throwing. If downstream code assumes the order has items, I would type it as non-empty with `.nonempty()` ("Strengthen a type only where partiality appears").
