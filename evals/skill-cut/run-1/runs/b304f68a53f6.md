First, I don't bolt on `cancelledAt?: Date`. That would add a second optional field to a type that already allows `status: 'done'` with no `doneAt`. Instead I follow "Make illegal states unrepresentable" and rewrite `Task` as a sum type:
`type Task = { status: 'open' } | { status: 'done'; doneAt: Date } | { status: 'cancelled'; cancelledAt: Date };`
Next, under "Exhaustive matching is the compiler's job," I add `const _exhaustive: never = task;` to the default branch of every `switch (task.status)`. Then I run `npx tsc --noEmit`, and each error it reports is a call site that now needs a `cancelled` case or must stop reading `doneAt` without narrowing.
Last, I find the parser that builds `Task` from JSON or DB rows ("External data is untyped until parsed") and update it to produce the new variants.
