First I check whether an `Order` schema or parser already exists to derive from. I'd grep for it with `Grep pattern="OrderSchema|parseOrder" path="src"`.

I'm following **"External data is untyped until parsed"** and **"Don't lie to the type system"**. The `as Order` cast is a lie at the boundary, and `order.items.length` will crash at runtime if `items` is missing.

If no parser exists, I add one, deriving the type from the schema instead of hand-rolling it (**"Derive types from authoritative schemas"**):

`const OrderSchema = z.object({ items: z.array(ItemSchema), /* … */ }); type Order = z.infer<typeof OrderSchema>;`

Then I replace the cast in the handler with:

`const parsed = OrderSchema.safeParse(JSON.parse(body)); if (!parsed.success) return badRequest(parsed.error); const order = parsed.data;`

After that, downstream code trusts `order.items` with no further checks.
