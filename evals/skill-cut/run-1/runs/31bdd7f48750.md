### Act On

1. **The eval's "won" verdict is not supported by its own evidence.** (A1, B1, merged) The two findings attack the same claim from different sides, and together they are decisive.
   - B1: the rule's "lost on none" condition passed only in run 2. Run 1 lost on outside (4 up, 6 down). The only change between the runs was the output format, and outside flipped sign on 8 of 10 cases.
   - A1: rescoring the committed briefs shows that run 2's whole outside gain comes from the backtick branch of `OUTSIDE`. Without it, the arms are level (0.34 vs 0.33). Deeper briefs simply use more inline code because the skill tells them to.

   This is the task's own "Proves it", so it matters most. The task also says plainly that a non-win is a finding.
   - **Fix:** drop the backtick branch, or narrow it to commands that are actually run.
   - Rescore both committed runs. This needs no model calls.
   - Restate the Result as what both runs agree on: raw and instruments up, proof outside not shown, no-loss condition not met in both runs. Do not report "won" from run 2 alone.

2. **The raw-sources measure has no control for echoing the skill's own list, but the README claims it does.** (A2, B2, consensus) Seven of the twelve `RAW` kinds are near-verbatim from `SKILL.md` question 2. The "not only by copying the skill's own examples" claim is backed only for instruments.
   - **Fix:** add a raw `beyond` count, rescore the committed briefs, and report what is left. Otherwise, narrow the sentence to instruments.

3. **The one documented command deletes the committed results before it can fail.** (A3, B3, consensus) `write()` runs `rmtree` on `runs/` and `deeper/` before 60 `claude -p` calls. `key.json` is written only at the end. Any failure leaves the results inconsistent, and `report` then refuses to run. This includes `claude` being missing, which B shows is the default path on a machine without it. "Rerunnable by one command" is a Done-when line.
   - **Fix:** write into a temp directory and swap it in after the key is written. Also check `shutil.which("claude")` up front.

4. **Redaction fails open when `XDG_CONFIG_HOME` is set.** (B4) `_private` hardcodes `~/.config` and swallows `jleak.Missing`. Cases and model outputs drawn from private task state can then be committed to a public repo with no redaction and no warning. This came from a single reviewer, but it is concrete and the cost is a leak.
   - **Fix:** resolve the config path the way `jleak.cli` does, and fail when the patterns are missing.
