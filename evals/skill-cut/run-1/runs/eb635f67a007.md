1. **First:** I check whether a schema (OpenAPI, protobuf, an existing zod schema) already owns `Order`. If one does, I derive the parser from it rather than writing a parallel type, per **"Derive types from authoritative schemas."**
2. **Section followed:** **"External data is untyped until parsed."** The `as Order` cast trusts the HTTP body without checking it, so `order.items.length` can throw at runtime.
3. **Line I write:** `const order: Order = parseOrder(JSON.parse(body) as unknown);`
4. **Parser:** `parseOrder` (or `OrderSchema.parse` if derived from a schema) validates `items` is an array and brands IDs like `OrderId` once, so downstream code can trust the type.
5. **Failure path:** a parse failure returns a 400 at the boundary instead of crashing deep in the handler.
