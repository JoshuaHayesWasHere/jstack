### Act On

**1. The depth-vs-breadth test contradicts the third question** (A1, B2; merged)
Line 15 says depth "reaches the same outcome", and wider work "changes the outcome", judged against the "Done when". Line 13 tells the reader to change what proves the work is done: a failing-then-passing test, a measured target, an outside judge. Applied literally, the test files the main thing depth adds under breadth, which then lands in "Noticed".
- This is the one new decision rule the rewrite introduces. The "Done when" asks for it ("and how to tell"), and it points the wrong way.
- Both reviewers found it on their own and traced a concrete misuse, which makes it the strongest finding in the review.
- **Fix:** key the test on deliverables. Deeper work keeps the deliverables and changes where the work starts, what it measures with, and what judges it. Wider work adds a deliverable. Also fix the line "answers them by adding a deliverable" that B2 flags.

**2. "say why it is reasonable" changes the rule** (B1)
The rule was to ask for an ambitious target and *tell the worker it is reasonable*. That is a prompting move. The new text makes it a duty to justify the target.
- The principle now disagrees with `skills/deeper/SKILL.md` question 4, which this task may not touch, and with the credit in `THIRD_PARTY.md:260`.
- The task asked for a change of style, not a change of rule.
- Only one reviewer raised this, but the meaning change is concrete and checkable against two other files.
- **Fix:** restore "and say it is reasonable". If the style needs a reason, add a clause on why stating it works.

**3. The instruments point is made twice and breaks the paragraph's chain** (A2, B3; merged)
"Naming a method without the command that runs it here is still words" (line 7) repeats line 12. It also interrupts the argument running from digested input to self-judging.
- In a prose-only PR whose deliverable is "reads like #633", redundancy is a defect, not a nit.
- The file is now the longest of the 25 principles. The #633 rewrites run to at most 475 words; this one is 710.
- Both reviewers flagged it, and the fix is one deleted sentence.
- **Fix:** drop the sentence from line 7. A's further trim of the line 5 restatement is optional.
