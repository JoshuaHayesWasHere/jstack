### Intent

   - The only fix is editing the brief. That changes its sha, which needs a new approval. This is exactly the stranded row the "Done when" rules out.
   - Both reviewers traced the same concrete path and checked the live queues, so this is a consensus finding.

   - This is a concrete, recurring path, not a hypothetical.

  - Tradeoff: fixing Act On #1 already touches this line. Switching to an aware datetime and parsing `ran_at` the way `digest.py:149` does costs little extra while that line is open. Otherwise it can wait.
