Shown as a table, a chart or a running total? Alert on what threshold, and through which channel, such as jbus's webhook to Sous Chef?
4. **Then:** I read `$T/plan-entry.md` and write one entry per pull-request-sized task in `$M/plan.md`, with `Stage: proposed`, a "Done when" list and the user's decisions in their words.
5. **Research:** only where an entry's brief cannot be written from `$H`, for example where the cost data comes from, I send a scout as "Sending a scout" says, a light `Explore` scout or `/scout <slug>`.
6. **Launch:** I launch nothing until the user approves the entries. Then I queue each brief with `jbus queue add --entry <entry>`, check `jgauge room`, and launch each crewmate.
